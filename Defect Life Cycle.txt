Q Diff Between Sevarity and Priority
| Point         | Severity                                      | Priority                                                 |

| Definition    | Severity defines how serious the defect is.   | Priority defines how quickly the defect should be fixed.|
| Focus         | Focuses on impact on application/functionality| Focuses on urgency of fixing the defect.                 |
| Decided By    | Decided by Tester / QA Team.                  | Decided by Manager / Client / Product Owner.             |
| Related To    | Technical impact.                             | Business importance.                                     |
| Types         | Critical, Major, Minor, Low.                  | High, Medium, Low.                                       |
| Main Question | “How severe is the bug?”                      | “How soon should it be fixed?”                           |
| Effect        | Affects system performance and functionality. | Affects release schedule and customer requ
